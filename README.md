# Pulse Leiloes Institucional

Quero que crie esse site que eu mencionei no prompt focado 100% em SEO, não só isso já tenho uma estrutura de uma landingpage que eu fiz com um blog dentro para um cliente também de leilão, quero aplicar o mesmo formato com todos os aspectos de SEO e Marketing e UX já pensados e aprimorados nesse site, tente usar linguagens de programação de front-end mais voltadas para o html, css e js e python do que outras linguagens se possível, mas se precisar outras linguagens pode usar é só pra dar uma prioridade nessas que mencionei, segue o site exemplo, lembrando que o Dr. Alexrandidis era meu antigo cliente então não vamos fazer uma pagina de professor podemos fazer uma pagina de outra coisa sem ser de uma pessoa, não queremos divulgar um leiloeiro em si, mas pense em marketing nessa parte e veja como o blog foi feito e a UX que ele foi feito melhore é claro como se fosse um especialista em marketing, seo e UX com as habilidades mais recentes e desenvolvidas e funcionais dessas áreas, veja também como é identidade visual da Pulse leilões com print de redes sociais e logos e arte feitas e print do site oficial, além do proprio link do site oficinal para você se inspirar https://www.pulseleiloes.com.br/proximos_leiloes/1/1/
